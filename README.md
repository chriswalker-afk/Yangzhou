# Yangzhou: A Living Scroll

An illustrated, living-city tile-laying game set in late-Qianlong-era Yangzhou.

The first development pass is an interactive camera and art proof of concept. The six-tile Slender West Lake starting scene, tile rotation, placement, zoom, animated waterways and gardens, and the complete design specification will be introduced in a feature branch and pull request.

This is an early prototype, not a finished or historically reviewed game.
